# 投票大厅 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让创建者在创建公开链接投票时可以选择是否进「投票大厅」，所有已核验用户都能在大厅发现并参与正在进行的公开投票。

**Architecture:** `Vote` 加一个 `listedInHall` 布尔列；创建接口写入，新增只读接口 `GET /api/votes/hall` 用一次批量查询返回进行中的公开投票；前端新增 `/hall` 页面，导航和首页加入口，创建页加开关。投票规则、分享链接、结果可见性、PDF、名单全部不动。

**Tech Stack:** Express + TypeScript + Prisma + SQLite（CommonJS，`apps/api`）；React + Vite + react-router（ESM，`apps/web`）；Vitest + supertest。

**Spec:** `docs/superpowers/specs/2026-11-13-vote-hall-design.md`

## Global Constraints

- 阶段不落库，一律用 `getVotePhase` 推导（`DRAFT` / `LIVE` / `ENDED`），前端不自行推断；所有时间用 UTC。
- 只有 `status === "APPROVED"` 的用户能看大厅、创建投票、投票。
- `Ballot` 不存 `userId`，只存 `pseudonym`；大厅响应不得包含任何投票者信息（假名、实名、名单）。
- 大厅只包含 `listedInHall = true` 且 `participationMode = "OPEN_LINK"` 且 `LIVE` 的投票；按 `createdAt` 倒序；最多 200 条。
- 邀请制投票不能进大厅：服务端对 `INVITE_ONLY + listedInHall` 返回 400。
- `GET /hall` 必须注册在 `/:id` 之前（`vote.routes.ts` 已有同类注释）。
- 每个测试文件在 `beforeEach` 里调用 `resetDb()` 和 `resetRateLimits()`。
- 改完代码按 `npm test` → `npm run typecheck` → `npm run build` 验证。

## Review Focus

1. **待核验用户打开大厅** —— 期望看到「完成实名核验后即可浏览」的提示，而不是白屏、无限骨架屏或原始报错。测试：Task 2 的 403 用例 + Task 3 的待核验状态。
2. **投票在 `endAt` 附近结束** —— 期望大厅里消失，不出现「点进去发现已结束」。测试：Task 2 的过期 `endAt` 用例。
3. **创建者勾选开关后切到邀请制再提交** —— 期望不报 400。测试：Task 1 的服务端拒绝用例 + Task 4 只在 `OPEN_LINK` 时发送字段。
4. **大厅为空 / 请求失败 / token 过期** —— 期望有可操作的空状态、重试按钮、去登录入口。验证：Task 3 的三种状态。
5. **200 条上限和并列 `createdAt`** —— 期望顺序稳定（`createdAt desc, id desc`），不会因为截断而看起来乱序。测试：Task 2 的排序用例。

在 `VoteService` 里新增方法（放在 `getMyVotes` 之前）：

```ts
async getHallVotes(viewerId: string): Promise<HallVoteItem[]> {
  const now = new Date();
  const candidates = await prisma.vote.findMany({
    where: {
      listedInHall: true,
      participationMode: "OPEN_LINK",
      closedAt: null,
      endAt: { gt: now },
    },
    orderBy: [{ createdAt: "desc" }, { id: "desc" }],
    take: 200,
    select: {
      id: true,
      title: true,
      description: true,
      creatorId: true,
      allowMultiple: true,
      startAt: true,
      endAt: true,
      createdAt: true,
      closedAt: true,
      participationMode: true,
      startedAt: true,
    },
  });

  const votes = candidates.filter((vote) => getVotePhase(vote, now) === "LIVE");
  if (votes.length === 0) return [];

  const ids = votes.map((vote) => vote.id);
  const creatorIds = [...new Set(votes.map((vote) => vote.creatorId))];

  const [creators, counts, histories] = await Promise.all([
    prisma.user.findMany({
      where: { id: { in: creatorIds } },
      select: { id: true, username: true },
    }),
    prisma.ballot.groupBy({
      by: ["voteId"],
      where: { voteId: { in: ids } },
      _count: { _all: true },
    }),
    prisma.userVoteHistory.findMany({
      where: { userId: viewerId, voteId: { in: ids } },
      select: { voteId: true },
    }),
  ]);

  const usernameById = new Map(creators.map((user) => [user.id, user.username]));
  const countByVote = new Map(counts.map((row) => [row.voteId, row._count._all]));
  const votedIds = new Set(histories.map((history) => history.voteId));

  return votes.map((vote) => ({
    voteId: vote.id,
    title: vote.title,
    description: vote.description,
    creatorUsername: usernameById.get(vote.creatorId) ?? "",
    allowMultiple: vote.allowMultiple,
    startAt: vote.startAt,
    endAt: vote.endAt,
    createdAt: vote.createdAt,
    votedCount: countByVote.get(vote.id) ?? 0,
    hasVoted: votedIds.has(vote.id),
    isCreator: vote.creatorId === viewerId,
  }));
}
```
